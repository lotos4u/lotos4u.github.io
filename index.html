kodi-youtube

A private media centre in a private home.

kodi-youtube is a personal, non-commercial setup: one Kodi media centre attached to a television in a private household, running the open-source YouTube add-on for Kodi with its owner's own Google API credentials.

It is not a product and not a service. There is nothing to install, nothing to sign up for, and no users other than the owner of the Google Cloud project this page belongs to. The page exists because Google requires a home page, a privacy policy and terms of service for any OAuth application that is not left in test mode.

What it does

  • Plays YouTube videos on a television, next to a local film and music library.
  • Uses the YouTube Data API v3 to search, to list channels and playlists, and to read the owner's own subscriptions and watch history.
  • Signs in with the owner's Google Account, so that subscriptions and history belong to that account rather than to an anonymous device.

Software

Kodi and the YouTube add-on are both open source and are not written by the owner of this page. This project is only a configuration of them.
