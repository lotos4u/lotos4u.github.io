Privacy policy

kodi-youtube · effective 20 September 2026

Who this covers

kodi-youtube is a private media centre used by one person, its owner. It has no other users, collects nothing from visitors of this page, and operates no servers.

What data it accesses

When the owner signs in with their Google Account, the application uses the YouTube Data API v3 to read and, at the owner's request, modify data belonging to that same account:

  • subscriptions, playlists, liked videos and the “Watch later” list;
  • watch history, so that a partly watched video resumes where it stopped;
  • public video, channel and search results, which are not personal data.

Nothing is read from any other Google service, and no data belonging to anyone other than the signed-in owner is accessed.

Where the data is kept

Access and refresh tokens, and any cached responses from the API, are stored locally on the media device in the home, inside the Kodi add-on's own data directory. They are never uploaded anywhere, never shared with third parties, and never used for advertising or analytics. This project has no database, no backend and no logging service.

Google API Services User Data Policy

kodi-youtube's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

  • Access can be withdrawn at any time at myaccount.google.com/permissions.
  • Signing out inside the add-on, or deleting its data directory on the device, removes the stored tokens and cached data immediately.

Changes

If this policy changes, the date above changes with it.
